## 🧭 页面功能

### 1. 今天要处理（置顶区）
- 自动列出**逾期未审视**的原则（红色标注，一键「去审视」）
- 今日该审视、临近到期的原则也会提示
- 昨天没做完的审视自动顺延到今天，不会凭空消失

### 2. 原则库
- 按 7 大分类筛选：生活 / 工作 / 学习 / 理财 / 思维模型 / 误判心理学 / 人生策略
- 关键词搜索（标题 / 要点 / 内容）
- 新增、编辑、删除原则；收藏常用原则
- 每条原则显示：核心要点、审视周期、上次审视时间、审视状态

### 3. 定期审视
- 对每条原则打分（1-5 星）+ 判定（坚持 / 部分坚持 / 违反）
- 记录「践行情况」（最近做到了什么）和「反思」（为什么 / 怎么改进）
- **可关联个人目标**（减脂 / 求职 / 阅读 / 副业）：审视时选择关联目标并同步更新目标进度%，审视与目标联动
- 审视历史完整保留，可随时回顾删除

### 4. 原则日志（每天应用哪条原则）
- 记录**当天真实场景**下应用了哪条原则：场景 → 具体做了什么 → 反思收获
- 每条日志可自评（1-5 星），见证原则如何一点点改变行为
- 支持按日期 / 原则 / 内容搜索，可删除

### 5. 数据统计
- 原则总数、已审视数、待处理数、坚持率
- **个人目标进度看板**（四大目标进度条）
- 分类分布环形图、审视评分趋势折线图、审视次数排行

## 🔄 数据安全

- **在线模式**：数据自动同步到资料库云端（右上角显示「已同步」绿点）
- **离线模式**：网络异常时自动切换本地缓存（显示「离线模式」红点），恢复后自动同步
- 数据积累后建议定期导出备份（可在资料库数据表中查看原始数据）

## 🌱 使用建议（个人反思流程）

1. **每天**：在「原则日志」记一条今天实际应用了哪条原则的场景与做法
2. **每周**：打开工作台，看「今天要处理」有哪些原则逾期，点「去审视」：诚实打分 → 写下这周具体践行了什么 → 反思为什么没做到 → 关联相关目标并更新进度
3. **每月**：抽 30 分钟看「数据统计」，观察目标进度条与审视趋势，调整行为
4. **定期**：修改、新增原则，让原则库随认知成长而进化
