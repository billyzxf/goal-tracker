## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 2.1252 亿股（来源：财报 CSV + H1 外推情景，中性档与招商中报后预测 5.67 亿对齐）；合理PE = 13/17/21 倍（依据：2026 增速换挡至个位数-15%、风电装机节奏周期性、海外关税不确定性 → 低于 2022-2025 CAGR 50.6% 对应的倍数；现价 13.2× PE动、招商对应 2026E 12.3×；中性 17× 兼顾 2027-2028 恢复与 AIDC 第二曲线期权）
- 计算：保守 2.50×13 = 32.5 元；中性 2.65×17 = 45.1 元；乐观 2.88×21 = 60.5 元
- **合理股价区间：32.5 ~ 45.1 ~ 60.5 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：BPS = 14.65 元（equity 31.14 亿 ÷ 2.1252 亿股，2026Q2）；合理PB = 2.2/2.8/3.4 倍（锚定 ROE：2025 年 19.1%、2026E 中性约 17%、保守约 16% → 16-19% 档对应 2.2~3.4 倍；轻资产高现金无有息负债支撑上限）
- 计算：保守 14.65×2.2 = 32.2 元；中性 14.65×2.8 = 41.0 元；乐观 14.65×3.4 = 49.8 元
- **合理股价区间：32.2 ~ 41.0 ~ 49.8 元**
- ⚠️ 交叉验证信号：现价 PB 2.24 几乎贴着保守档——市场按"2026 零增长"定价，与 PE(动) 13.2× 相互印证

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 20.5/21.5/22.9 亿（H1 实际 + H2 外推，中性≈招商 21.03 亿）；合理PS = 3.5/4.7/5.9 倍（依据：净利率 27~28% 的高毛利设备，与 PE 档位自洽——PS 4.7×净利率约 27.5% ≈ 隐含 PE 17；现价隐含 TTM PS 3.45）
- 计算：保守 20.5×3.5÷2.1252 = 33.8 元；中性 21.5×4.7÷2.1252 = 47.5 元；乐观 22.9×5.9÷2.1252 = 63.5 元
- **合理股价区间：33.8 ~ 47.5 ~ 63.5 元**

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 8/18/25%（来源：2027-2028 恢复与第二曲线正常化增速——一致预期 2025→2028 净利 CAGR 22.7% 打折取中性 18%；保守 8% 反映风电装机回落情形；招商中报后 2026-2028 净利 CAGR 42% 不作基准）
- 适用性检查：2026H1 净利 +0.5% 主因汇兑损失 5116 万（一次性、随汇率波动），剔除后经营性利润 +19.8%，**可用**；但 g 需反映装机周期回落风险，不取历史 CAGR 50.6%
- 计算：保守 2.50×8 = 20.0 元；中性 2.65×18 = 47.7 元；乐观 2.88×25 = 72.0 元
- **合理股价区间：20.0 ~ 47.7 ~ 72.0 元**（PEG 对周期回落情形最敏感，保守档作深度安全边际参考）

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 2026E 净利 × 转换率（0.45/0.55/0.65——2025 年 OCF/净利 51%、应收增长快，取中低档）；g₁ = 8/15/22%；注：货币资金 11.38 亿（约 5.35 元/股）+ 近零有息负债未单列加回，若按净现金加回各档上移约 5.3 元，口径已偏保守
- 计算（股权价值 → 每股，÷2.1252 亿股）：
  - 保守：FCF₀=5.32×0.45=2.39 亿，g₁=8% → 43.5 亿 → **20.5 元**
  - 中性：FCF₀=5.64×0.55=3.10 亿，g₁=15% → 74.8 亿 → **35.2 元**
  - 乐观：FCF₀=6.12×0.65=3.98 亿，g₁=22% → 125.7 亿 → **59.1 元**
- **合理股价区间：20.5 ~ 35.2 ~ 59.1 元**

## 六、后续跟踪清单（目标：判断估值价格能否实现及延续）

### ① 财务指标跟踪（当前值 + 关键阈值）

- 单季净利增速：当前 Q2 单季 -17.7%（Q1 +30.7%，减速明显）；阈值：Q3 单季同比转正 → 中性情景确立可加仓；连续两季 <-15% → 下修至保守档 27.8 元中枢
- 毛利率：当前 48.84%（H1 同比 -1.31pct；Q2 单季 47.5%，同比约 -3.6pct，海外高毛利收入占比下降所致）；阈值：全年 <46% → 盈利结构恶化，PE 锚下修至 13 倍；Q3 回升至 49%+ → 海外恢复与高毛利订单回归信号
- 经营现金流与应收：当前 OCF/净利 24%（H1，2025 全年 51%）；应收 7.04 亿占 LTM 营收 34.8%（壹评级 2026-07-20 指出回款管理承压、应收随规模扩张攀升）；阈值：全年 OCF/净利 <40% 且应收占比 >40% → 收入质量预警；回款改善 → DCF 转换率上调
- 汇兑损益：当前 H1 损失 5116 万（财务费用率同比 +5.68pct，蓝鲸新闻 2026-08-25）；阈值：人民币再升值 → 保守档概率上升；企稳 → 剔除后 +19.8% 的经营性增速显性化，利好情绪与估值修复
- ROE：当前 2025 全年 19.11%、2026E 中性约 17%；阈值：全年跌破 16% → PB 锚下修至 2.2 倍以下；维持 18%+ → PB 锚维持 2.8 倍以上

### ③ 隐藏变量（影响估值兑现的因素）

- 风电抢装透支（最关键）：2025 年国内新增装机 1.3 亿千瓦 +49.9%（抢装），2026H1 -26.5% 是高基数扰动还是趋势回落起点尚未验证；影响方向：若 2027 装机继续回落，保守情景概率大增，估值中枢向 27.8 靠拢
- 汇率与关税（双向变量）：海外收入占比 46%（2025 年 52%），汇兑损失 5116 万 + 北美关税同时压制 H1 利润；影响方向：企稳/缓和 → 利润弹性集中释放；继续恶化 → 保守档
- AIDC 估值重塑的不确定性：变压器业务能否获得北美 AIDC 订单截至 2026-08-29 尚无实锤（为券商预期逻辑）；影响方向：兑现则估值体系切换上移（招商"EPS+PE 双击"），不兑现则回归风电零部件估值，且并购整合费用前置
- 下游客户集中与传导：依赖全球主要风机制造商，风机价格战对零部件采购价的传导压力（类比汽车年降）；影响方向：毛利率长期缓慢承压，需跟踪对大客户的议价与新品溢价
