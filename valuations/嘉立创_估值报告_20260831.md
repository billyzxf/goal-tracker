## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 5.5556 亿股（来源：财报 CSV + 情景外推）；合理PE = 24/28/32 倍（依据：PCB 行业中枢 25~40 倍；国泰海通远期公允区间隐含 2026E PE 26.5~29.6 倍；平台属性溢价由现金流与增速支撑，不给予互联网平台型 40 倍+溢价，因盈利仍以制造为主）
- 计算：保守 3.46×24 = 83.0 元；中性 3.65×28 = 102.2 元；乐观 3.85×32 = 123.2 元
- **合理股价区间：83.0 ~ 102.2 ~ 123.2 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：BPS = 约 23 元（募资后口径：报表 equity 82.35 亿 + IPO 净募资约 47 亿 ≈ 129 亿 ÷ 5.5556 亿股；行情源 PB 7.67 与此互洽）；合理PB = 3.5/4.5/5.5 倍（锚定募资摊薄后 2026E ROE 约 15%（20.3 亿 ÷ 约 135 亿年末净资产），属 ROE 10~20% 档 2~4 倍上浮至 3.5~5.5，平台现金流质量给予上沿）
- 计算：保守 23.0×3.5 = 80.5 元；中性 23.0×4.5 = 103.5 元；乐观 23.0×5.5 = 126.5 元
- **合理股价区间：80.5 ~ 103.5 ~ 126.5 元**

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 132/139/145 亿（来源：H1 外推 + 保荐人报告）；合理PS = 5/6/7 倍（依据：净利率 14.6%（中性）× 中性 PE 28 → 隐含 PS 约 4.1 倍；考虑 3.0% 应收占比 + 123% OCF/净利的优异收入质量，给予溢价至 6 倍；注意元器件贸易占营收近四成且低毛利，整体 PS 不宜对标纯软件平台）
- 计算：保守 132×5÷5.5556 = 118.8 元；中性 139×6÷5.5556 = 150.1 元；乐观 145×7÷5.5556 = 182.7 元
- **合理股价区间：118.8 ~ 150.1 ~ 182.7 元**（现价隐含 2026E PS 约 7.0 倍，介于中性与乐观之间）

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 25/32/40（来源：正常化增速；2025→2028 参考：保荐人 2028E 21.79 亿 → CAGR 18.6% 偏保守，H1 动量 +55% 偏激进，取中间正常化 32%；公司 2022 年曾 -13%，长尾需求随研发景气波动，g 不宜取 50%+）
- 适用性检查：非周期暴增（AI 硬件/机器人研发打样为结构性增量），**可用**；但上市时间短、盈利预测外部锚缺失，g 的不确定性高于同业，PEG 结果仅作参考中枢
- 计算：保守 3.46×25 = 86.5 元；中性 3.65×32 = 116.8 元；乐观 3.85×40 = 154.0 元
- **合理股价区间：86.5 ~ 116.8 ~ 154.0 元**

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 2026E 净利 × 转换率 0.85/0.90/0.95（2026H1 OCF/净利 123%，先款后货 + 合同负债增长，转换率取行业内最高档）；g₁ = 20/28/35%
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=19.2×0.85=16.3 亿，g₁=20% → 477.8 亿 → **86.0 元**
  - 中性：FCF₀=20.3×0.90=18.3 亿，g₁=28% → 720.8 亿 → **129.7 元**
  - 乐观：FCF₀=21.4×0.95=20.3 亿，g₁=35% → 1028.8 亿 → **185.2 元**
- **合理股价区间：86.0 ~ 129.7 ~ 185.2 元**

## 四、触发线与操作（Step4）

- 深度买点 = 保守均值×0.9 = **81.9 元**（重仓区，接近发行价 84.46 元）
- 第一买点 = 中性均值×0.85 = **102.4 元**（分批建仓）
- 中性持有 = 中性均值±5% = **114.5 ~ 126.5 元**（持有不动）
- 止盈观察 = 中性均值×1.2+ = **144.6 元+**（可减 1/3 锁利）
- 透支卖出 = 乐观均值×1.05 = **162.0 元+**（减仓）
- 两剧本：剧本A（次新情绪继续发酵 + H2 业绩超预期）→ 162 元上方坚决减仓，情绪定价不可作为持有依据；剧本B（情绪退潮/解禁临近/业绩不及预期）→ 回落 102.4 元下方分批，81.9 元（发行价附近）错杀重仓

## 五、结论

- 现价 175.01 元 vs 中性均值 120.5 元 → **高估 45%，已越过透支卖出线 162.0 元（超 8%）**
- 操作建议：**持有者逢高减仓（至少 1/3），空仓者不参与情绪博弈**；现价较乐观均值 154.3 元仍高 13%，需 H2 净利增速维持 55%+ 且次新情绪延续才能维持；若回落至第一买点 102.4 元下方（接近发行价一档），基本面与情绪双锚支撑，可分批布局
- 核心前提：本估值成立依赖"H2 增速维持 40%+ + 平台模式现金流优势持续 + 次新溢价理性回归"。当前定价中含大量小流通盘情绪溢价，**该部分无法用五方法验证，是现价与基本面锚之间约 55 元/股（≈300 亿市值）的主要差距**

## 六、后续跟踪清单（目标：判断估值价格能否实现及延续）

### ① 财务指标跟踪（当前值 + 关键阈值）

- 经营现金流：当前 12.65 亿（2026H1，OCF/净利 123%，2025 全年 19.04 亿/净利 146%）；阈值：全年 OCF/净利 <80% → 平台先款后货优势弱化，下调 DCF 转换率与整体中枢
- 净利增速：当前扣非 +81.3%（H1）；阈值：全年扣非累计同比跌破 +40% → 下修至保守档；跌破 +25% → 五方法中枢整体下移（参考 2022 年 -13% 的历史下行）
- 毛利率：当前 28.41%（2025 全年 28.13%，基本持平）；阈值：高多层占比提升本应推动毛利率上行，若连续两季下滑 >2pct → 产品结构升级逻辑证伪，PE 向 20~25 倍压缩
- 应收账款：当前 3.86 亿（占 LTM 营收 3.0%）；阈值：占比升至 8%+ → 平台先款后货模式动摇，收入质量预警（当前为全行业最优水平，重点保持项）
- ROE：2025 全年 20.11%；IPO 募资后净资产基数抬升约 60%，摊薄后 2026E 约 15%；阈值：2027 年 ROE 无法回升至 18%+ → 募投项目回报低于预期，PB 锚下移

### ③ 隐藏变量（影响估值兑现的因素）

- **次新筹码结构（最关键）**：2026-08-04 上市，流通比例仅约 7.9%，上市首日冲 234 元后回落，换手 31.5%（8/28），当前价格含大量筹码稀缺情绪溢价；一年后限售解禁（大股东+战配）将根本性改变供需（影响方向：负面，解禁前情绪溢价随时收敛）
- 战略配售：建滔系与宁德时代首次以战略配售方式投资外部独立 PCB 企业（来源：2026-08-09 市场文章，未联网二次核实）——若属实为产业资本背书（正面），但战配股份解禁节奏需跟踪
- 商业模式双属性：约四成营收来自低毛利元器件贸易（引流工具），利润依赖 PCB 制造 + PCBA；市场若按"产业互联网平台"给 50~100 倍 PE 属于情绪定价，按制造+平台混合给 25~32 倍是本报告口径（影响方向：决定估值分歧幅度）
- 周期属性：2021-2022 年净利曾负增长（消费电子研发收缩），长尾打样需求与全社会研发景气正相关，并非完全弱周期（影响方向：研发景气回落时双杀）
