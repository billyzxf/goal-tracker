## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 10.9083 亿股（来源：财报 CSV + 情景假设）；合理PE = 30/35/40 倍（依据：光器件平台型、无源毛利率 71.9%、客户绑定英伟达/Fabrinet/旭创，享受高于光模块整机的倍数；但 Q2 营收转负为重大警示，倍数不给到历史高位）
- 计算：保守 2.28×30 = 68.4 元；中性 2.64×35 = 92.4 元；乐观 3.15×40 = 126.0 元
- **合理股价区间：68.4 ~ 92.4 ~ 126.0 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = 2026E 年末 BPS × 合理PB
- 输入：年末 BPS =（2025 末 equity 55.13 亿 + 2026E 净利×留存 0.80，分红数据缺失按 20% 分红率假设）÷ 股本 → 保守 6.88 / 中性 7.17 / 乐观 7.58 元；合理PB = 10/13/17 倍（依据：PB = PE×ROE 自洽，2026E 期末 ROE 33~42%）
- 计算：保守 6.88×10 = 68.8 元；中性 7.17×13 = 93.2 元；乐观 7.58×17 = 128.9 元
- **合理股价区间：68.8 ~ 93.2 ~ 128.9 元**
- ⚠️ 交叉验证：现价 PB 46.01 为中性合理值的 3.5 倍，透支幅度为五方法中最直观的证据

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 56.7/64.8/75.7 亿（来源：情景外推，一致预期 85.91 亿）；合理PS = 13.2/15.5/18.2 倍（依据：PS = PE×净利率自洽，净利率 44~45%——净利率为四家光模块链公司最高，支撑高 PS）
- 计算：保守 56.7×13.2÷10.9083 = 68.6 元；中性 64.8×15.5÷10.9083 = 92.1 元；乐观 75.7×18.2÷10.9083 = 126.3 元
- **合理股价区间：68.6 ~ 92.1 ~ 126.3 元**

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 25/35/45%（来源：正常化增速——2026→2028E 一致预期 CAGR 51%，2028 后行业增速回落，取正常化区间；不用当年 +43~71%）
- 适用性检查：2022-2025 连续四年高增长、无周期负增长史，增长由 AI 光互连架构升级驱动，**可用**；股权激励考核目标（2027-2029 较 2025 +150%/+400%/+700%）隐含 2026-2029 CAGR 44%，与本取值中枢一致
- 计算：保守 2.28×25 = 57.0 元；中性 2.64×35 = 92.4 元；乐观 3.15×45 = 141.8 元
- **合理股价区间：57.0 ~ 92.4 ~ 141.8 元**

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，TV = FCF₅×(1+g₂)/(r-g₂)，r=10%，g₂=3%
- 输入：基期 FCF = 2026E 净利 × 转换率（2025 OCF/净利 92.6%、2026H1 83.1%，轻资产高现金转换，取 0.80/0.90/0.95）；g₁ = 15/22/30%
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=24.9×0.80=19.9 亿，g₁=15% → 479.3 亿 → **43.9 元**
  - 中性：FCF₀=28.8×0.90=25.9 亿，g₁=22% → 819.2 亿 → **75.1 元**
  - 乐观：FCF₀=34.4×0.95=32.7 亿，g₁=30% → 1386.6 亿 → **127.1 元**
- **合理股价区间：43.9 ~ 75.1 ~ 127.1 元**
