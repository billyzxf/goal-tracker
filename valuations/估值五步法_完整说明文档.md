# 第一部分：估值五步法·总流程（操作步骤）

```
Step1 拉数据 → Step2 定预测 → Step3 跑五方法 → Step4 定触发线 → Step5 跟踪验证
```

## Step 1：拉数据（财务三表+关键项）—— 已脚本化/持久化

**必拉数据清单 → 当前项目数据来源对照**（✅=脚本自动抓取并持久化，导入估值模块即可用）：

| 数据项 | 持久化位置 / 字段 | 来源脚本 | 状态 |
|--------|------------------|---------|------|
| 营收/净利/扣非净利（累计，近N季度） | data/financial/{代码}_{公司}.csv → revenue/netProfit/deductedNetProfit | fetch_financial.py | ✅ |
| 营收同比%、扣非净利同比% | 同上 → revenueYoy/deductedNetProfitYoy | fetch_financial.py | ✅ |
| 毛利率、净利率、ROE、资产负债率、总资产周转率 | 同上 | fetch_financial.py | ✅ |
| 总资产/所有者权益/毛利润 | 同上 → totalAssets/equity/grossProfit | fetch_financial.py | ✅ |
| 经营现金流、资本开支（→FCF） | 同上 → opCashFlow/capex | fetch_financial.py | ✅ |
| **应收账款/存货/合同负债/货币资金** | 同上 → accountsReceivable/inventory/contractLiab/cash | fetch_financial.py（资产负债表） | ✅ |
| BPS（每股净资产） | 由 equity ÷ 总股本 在估值模块内推算 | —（无需单独抓） | ✅ |
| 现价/总股本/总市值/PE(动)/PB | data/prices/当前股价_YYYYMMDD.csv | fetch_prices.py | ✅ |
| 机构一致预期（EPS/净利/营收，按年） | data/forecast/盈利预测_{公司}.csv → 一致预期+券商明细 | fetch_profit_forecast.py | ✅ |
| 同业估值对比（PE/PB 横向） | 股价 CSV 内含各公司 PE/PB，可横向排序对比 | fetch_prices.py | ⚠️ 半自动（需人工横向比较） |
| 行业景气信号 | 宏观模块（GDP/CPI/PPI/PMI，data/macro/） | fetch_macro_all.py / fetch_daily.py | ⚠️ 半自动（宏观面，行业面需人工） |
| 业绩预告（三情景辅助） | 未持久化；eastmoney.py 已封装 predict()，按需临时调用 | —（可选） | ⚠️ 可选 |

**一键取数流程（估值一家新公司的标准动作）**：

> ⚠️ 先查本地再抓取：`data/financial/`、`data/prices/`、`data/forecast/` 已存在该公司数据且覆盖最新报告期/最新交易日的，直接使用本地数据，不要重复执行脚本；仅在缺数据或数据过期时才跑对应命令。

```bash
# ① 财务三表（默认读 data/公司列表.csv 批量，或 --ticker 单只）
py scripts/fetch_financial.py --auto --quarters 18
# ② 盈利预测/一致预期（Step2 定预测的锚）
py scripts/fetch_profit_forecast.py --auto
# ③ 全部公司行情快照（现价/PE/PB/总市值/总股本）
py scripts/fetch_prices.py
```

然后在浏览器「公司估值」→「⬆ 批量导入财务」「⬆ 批量导入预测」「⬆ 导入股价」选对应 CSV 即可。
数据均为"报告期累计值"口径，与估值模块一致；导入按「股票代码+季度」合并，不覆盖手工数据。

**人工补充项**（脚本不覆盖，分析时手动填入）：
- [ ] 同业估值对比表：从股价 CSV 取同行业公司 PE/PB，横向比较后确定"合理倍数"
- [ ] 行业景气判断：结合宏观模块数据 + 行业新闻/订单新闻（如 AI 服务器扩产、存储涨价）
- [ ] 业绩预告区间（如有）：可用 `python -c "from eastmoney import EastmoneyClient; print(EastmoneyClient().predict('601138.SH'))"` 临时查询

## Step 2：定预测（业绩三情景）

**输出**：未来1年（2026E）净利润三情景 + 对应EPS

| 情景 | 定义 | 示例（浪潮2026E） |
|------|------|------------------|
| 保守 | 已实现部分+H2持平 | 59.5亿（H2与H1持平） |
| 中性 | H2温和增长 | 65.5亿（H2 +20%） |
| 乐观 | 逻辑顺利兑现 | 71.5亿（H2 +40%） |

**要点**：
- 以最新财报为锚外推，参考机构一致预期（盈利预测模块「一致预期」表，来自 fetch_profit_forecast.py）
- 2026E净利 = H1实际 + H2预测
- 特殊处理：周期股用"正常化盈利"；亏损修复期用"拐点增速"

## Step 3：跑五方法（工具箱，见第二部分）

**输出**：5×3矩阵（5种方法×3档情景）= 15个估值点

**统一口径要求**：五种方法必须用同一年份的EPS/营收/BPS（如都用2026E），防止口径错配

**工具衔接**：PE/PB/PS/PEG/DCF 五种方法已在估值模块内置（公司详情 → 「💰 估值记录」→「＋ 添加估值」选方法）。
三情景各存一条估值记录（如"浪潮-中性-PE"），备注标注情景，模块自动算出估算价值与安全边际（现价/估算值）。

## Step 4：定触发线（把估值变成买卖点）

**输出**：三档价格区间 + 明确的操作动作

| 区间 | 计算 | 动作 |
|------|------|------|
| 买入区 | 中性值×0.85~保守值 | 分批买入 |
| 中性合理区 | 保守~中性均值 | 持有不动 |
| 止盈观察区 | 中性~乐观值 | 涨入此区不追高，可减1/3锁利 |
| 透支区 | >乐观值 | 减仓 |

**附加**：两剧本预案（利好落地→剧本A买点；利空杀跌→剧本B错杀点）

## Step 5：跟踪验证（估值是动态的）

- 每季财报后用 fetch_financial.py 重抓财务 + fetch_prices.py 更新行情，导入估值模块；
  财报跟踪模块可设置各公司财报披露日期提醒，对照《跟踪清单》逐项验证（毛利率/现金流/订单，
  新增的应收账款/存货/合同负债也可在分季度财务表中按渐变色行对齐同比观察）；
  更新跟踪清单时**联网搜索该公司最新券商研报与行业动态**校准阈值、补充验证信号（见《估值报告生成SOP》硬性要求第4条）
- **业绩证伪信号 → 下调预测、重算估值**（德赛西威案例：2025年报好→2026中报增速断崖→估值下调）
- **业绩超预期信号 → 上调预测、重算估值**（浪潮案例：中报毛利率翻倍→中枢从86上移到110）

# 第二部分：五方法详解（工具箱）

## 方法一：市盈率法（PE法）—— 万能主力工具

**公式**：合理股价 = EPS × 合理PE

**输入**：2026E净利三情景 ÷ 总股本 = EPS；再乘以合理PE倍数

**适用**：绝大多数盈利稳定的公司（首选）

**合理PE取值参考**：

| 公司类型 | PE区间 | 说明 |
|---------|--------|------|
| 成熟价值股（海康） | 20-30倍 | 稳健增长 |
| 成长股（深南） | 30-45倍 | 高增速+行业景气 |
| AI算力核心（浪潮） | 25-35倍 | 景气+拐点确认 |
| 周期股顶部（兆易） | **15-20倍** | ⚠️ 盈利不可持续，压低 |
| 增速放缓股（德赛） | 18-26倍 | 增速下修时同步下调 |

**优点**：直观、市场通用、数据易得
**缺点**：亏损公司无法用；周期顶部会"骗人"（低PE陷阱）

**实战案例**：浪潮2026E中性EPS 4.46 × 30倍 = 134元

---

## 方法二：市净率法（PB法）—— 资产型公司首选

**公式**：合理股价 = BPS × 合理PB

**输入**：最新BPS（每股净资产，随财报更新）× 合理PB倍数

**PB取值锚定ROE**：

| ROE水平 | 合理PB | 逻辑 |
|---------|--------|------|
| ROE≥20% | 4-6倍 | 高回报资产 |
| ROE 15-20% | 3-5倍 | 优秀 |
| ROE 10-15% | 2-3.5倍 | 一般 |
| ROE<10% | 1-2倍 | 平庸 |

**适用**：重资产公司、周期股、金融股、ROE稳定的公司
**优点**：净资产比利润稳定，周期波动中更可靠
**缺点**：轻资产公司（软件/品牌）账面净资产失真

**实战案例**：浪潮中报BPS 16.71，年末预估18.5 × 5倍 = 92元

---

## 方法三：市销率法（PS法）—— 亏损/低利润公司专用

**公式**：合理股价 = 2026E营收 × 合理PS ÷ 总股本

**PS取值参考**：

| 公司类型 | PS区间 | 说明 |
|---------|--------|------|
| 高毛利存储（兆易63%毛利） | 6-12倍 | 盈利弹性大 |
| PCB龙头（深南28%毛利） | 2-3.5倍 | 制造业中高端 |
| AI硬件代工（浪潮） | 0.5-0.8倍 | 低毛利高周转 |
| 汽车电子（德赛19%毛利） | 1-2倍 | 规模优先 |

**适用**：亏损公司、盈利刚反转的公司、高增长低利润公司
**优点**：营收比利润难造假，能捕捉"利润率拐点前"的价值
**缺点**：忽略盈利质量差异（同样营收，毛利率差5倍的公司不能同倍数）

**实战案例**：浪潮2026E营收1800亿 × 0.65 ÷ 14.68 = 80元（PS法通常给出最低值，做下限参考）

---

## 方法四：PEG法 —— 成长股估值校正器

**公式**：合理PE = 未来3年复合增速g（PEG=1），合理股价 = EPS × g

**输入**：未来3年预期复合增速（不是当年增速！）

**适用**：**增速可持续的成长股**

**⚠️ 两大禁区**：
1. **周期股禁用**——兆易H1 +1091%是涨价脉冲，用PEG会算出657元荒谬值
2. **暴增当年慎用**——浪潮2026E+150%不可持续，要用正常化后的g（22-35%）

**实战案例**：浪潮正常化g=28% → EPS 4.46 × 28 = 125元；德赛增速下修至14% → 只值66元

---

## 方法五：DCF折现法（两阶段）—— 终极检验工具

**公式**：
```
股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵
其中：FCF = 正常化净利 × 转换率（0.85-0.9）
     r = 10%（股权成本）
     g1 = 高增长期增速（5年），g2 = 永续增速（3%）
```

**输入**：正常化净利、g1、g2、r

**参数参考**：

| 参数 | 常用取值 |
|------|---------|
| FCF转换率 | 0.85-0.9（现金流好的公司取高值） |
| g1 | 成熟公司10-15%；成长公司20-30% |
| g2 | 3%（长期名义GDP） |
| r | 10% |

**适用**：所有有盈利的公司（终极交叉验证）
**优点**：贴近内在价值本质
**缺点**：对参数敏感（g1差5%，结果差30%）；周期股需用正常化盈利

**实战案例**：浪潮基期FCF 55亿、g1=22% → 119元

# 第五部分：常见错误清单（避坑）

1. **口径错配**：PE用2026E的EPS，PEG却用2025年增速 → 必须统一年份
2. **周期顶部用高PE**：兆易+1091%时给40倍 = 天价接盘 → 周期顶部压倍数
3. **忽略增速变化**：德赛从+22%降到+1.8%，PE还按老标准给 → 增速下修倍数同步下修
4. **单方法迷信**：PS法永远最低、PEG法对暴增公司永远最高 → **必须五方法交叉验证取均值**
5. **静态估值**：财报一出必须重算（浪潮中报后中枢上移26%）→ 估值是动词不是名词
6. **忘记安全边际**：中性值≠买点，买入要打折（中性×0.85以下）
7. **预测过于乐观**：乐观情景是"如果一切顺利"，不能当基准

# 第六部分：估值 → 触发线 → 操作（落地模板）

```
输入：五方法3×5矩阵
  ↓
计算：中性均值（5个中性值的平均）
  ↓
输出四档：
  深度买点 = 保守值×0.9     （重仓区）
  第一买点 = 中性均值×0.85   （分批建仓）
  中性持有 = 中性均值±5%    （持有不动）
  止盈观察 = 中性均值×1.2+  （可减1/3）
  透支卖出 = 乐观值×1.05    （减仓）
  ↓
叠加两剧本：
  剧本A（利好落地）= 中性值附近分批
  剧本B（利空杀跌）= 保守值附近错杀买入
```
