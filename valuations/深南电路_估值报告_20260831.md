## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 6.8117 亿股（来源：财报 CSV + 情景假设）；合理PE = 28/33/38 倍（依据：同业动 PE 40~61 倍；可比公司 2027E 35~37 倍（招银/大摩）；2026-2028E CAGR 约 50% 对应 PEG<1）
- 计算：保守 7.19×28 = 201.3 元；中性 8.29×33 = 273.6 元；乐观 9.61×38 = 365.2 元
- **合理股价区间：201.3 ~ 273.6 ~ 365.2 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：BPS = 26.52 元（来源：equity 180.63 亿 ÷ 股本，2026Q2）；合理PB = 7/8/9 倍（锚定 ROE 20.8%（2025）且趋势上行至 26~31%（中泰预测 2026-2028），属 ROE 20~30% 档 5~8 倍上浮；现价 PB 13.7 显著高于锚）
- 计算：保守 26.52×7 = 185.6 元；中性 26.52×8 = 212.2 元；乐观 26.52×9 = 238.7 元
- **合理股价区间：185.6 ~ 212.2 ~ 238.7 元**
- ⚠️ 交叉验证信号：现价 PB 13.7 倍需 ROE 持续站上 30% 才能消化（中泰预测 2027-2028 ROE 31%），基板业务盈利兑现是 ROE 上台阶的关键，该前提一旦证伪 PB 法最先杀估值

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 305/322.3/345 亿（来源：一致预期 + 外推）；合理PS = 3.5/4.5/5.5 倍（依据：净利率 14.7%→17.5% 上行通道，中性 PE 33 × 净利率 17.5% → 隐含 PS 上限约 5.8，取折扣）
- 计算：保守 305×3.5÷6.8117 = 156.7 元；中性 322.3×4.5÷6.8117 = 213.0 元；乐观 345×5.5÷6.8117 = 278.5 元
- **合理股价区间：156.7 ~ 213.0 ~ 278.5 元**（现价隐含 2026E PS 约 7.7 倍，高于乐观档）

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 25/32/40（来源：2025→2028E 净利 CAGR = (109.20/32.76)^(1/3)-1 ≈ 49%，封顶 40；中性再打 8 折取 32 作正常化；2023 年曾负增长提示其周期属性）
- 适用性检查：AI 算力结构性需求 + 封装基板国产化双驱动，非单纯涨价脉冲；但公司 2023 年净利 -14.8% 显示 PCB 中长周期属性，g 不用当年 +72% 而取正常化，**可用**
- 计算：保守 7.19×25 = 179.8 元；中性 8.29×32 = 265.3 元；乐观 9.61×40 = 384.4 元
- **合理股价区间：179.8 ~ 265.3 ~ 384.4 元**

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 2026E 净利 × 转换率 0.60/0.70/0.80（2026H1 OCF/净利 67%，但 capex 46.8 亿/半年、在建工程高企，扩产期自由现金流受压，取正常化水平）；g₁ = 20/28/35%
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=49.0×0.60=29.4 亿，g₁=20% → 860.7 亿 → **126.4 元**
  - 中性：FCF₀=56.5×0.70=39.6 亿，g₁=28% → 1560.4 亿 → **229.1 元**
  - 乐观：FCF₀=65.5×0.80=52.4 亿，g₁=35% → 2651.6 亿 → **389.3 元**
- **合理股价区间：126.4 ~ 229.1 ~ 389.3 元**

## 五、结论

### ③ 隐藏变量（影响估值兑现的因素）

- 周期位置：AI 算力上行周期中段，但公司 2023 年净利 -14.8% 证明 PCB 有中周期属性；券商 2028E 净利 89~149 亿区间极宽（平安 89 vs 开源 148），远期分歧大（影响方向：景气回落则戴维斯双杀）
- 折旧压力：在建工程 32.48 亿（较年初 +75.5%）+ H1 capex 46.8 亿，2026Q4 起广州二期等新产能转固，折旧将压制 2027 年利润率（影响方向：负面，需跟踪单季净利率）
- 封装基板国产化：FC-BGA/ABF 载板是国产算力芯片自主可控的关键卡脖子环节，若国产 AI 芯片放量加速，公司基板业务存在超预期空间（影响方向：正面，是最具弹性的隐藏期权）
- 存储周期：BT 载板盈利高度绑定存储景气，存储价格若见顶回落，基板业务毛利率（H1 31.35%，同比 +16.2pct）将回吐（影响方向：负面）
- 大股东与筹码：控股股东深天科技持股 62.61%（信息日期 2026-08-30 平安），机构持仓占流通盘 76.5%（2026-06-30），高集中度筹码在预期反转时波动放大（影响方向：放大波动）
