## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 18.3161 亿股（来源：财报 CSV + 情景假设）；合理PE = 30/36/42 倍（依据：PCB 同业 40-55 倍、光模块同业约 37 倍，公司 2026E 增速 +369%~513% 但净利率 11.5% 偏低且光模块有价格竞争，取两板块之间偏保守档）
- 计算：保守 3.55×30 = 106.5 元；中性 4.10×36 = 147.6 元；乐观 4.64×42 = 194.9 元
- **合理股价区间：106.5 ~ 147.6 ~ 194.9 元**（现价 195.62 恰在乐观档上沿）

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：BPS = 13.40 元（来源：equity 245.49 亿 ÷ 18.3161 亿股，2026Q2）；合理PB = 8/11/13.5 倍（锚定 ROE 2026E 约 30%（H1 12.88% 年化），高于同业 10-15% 档上沿，PB 取同业 13-19 倍的下段）
- 计算：保守 13.40×8 = 107.2 元；中性 13.40×11 = 147.4 元；乐观 13.40×13.5 = 180.9 元
- **合理股价区间：107.2 ~ 147.4 ~ 180.9 元**
- ⚠️ 交叉验证信号：现价 PB 14.70 已超乐观档 13.5 倍——市场按"光芯片 IDM 稀缺资产"给溢价，超出账面 ROE 可解释范围

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 590/650/700 亿（来源：情景假设/券商预测）；合理PS = 4.5/5.5/6.5 倍（依据：毛利率 20.2%、净利率约 11.5%，低于沪电等高端 PCB 厂；但光模块 39% 毛利率业务占比提升构成结构升级溢价）
- 计算：保守 590×4.5÷18.3161 = 144.9 元；中性 650×5.5÷18.3161 = 195.1 元；乐观 700×6.5÷18.3161 = 248.5 元
- **合理股价区间：144.9 ~ 195.1 ~ 248.5 元**（现价隐含 2026E PS 约 5.5 倍，恰在 PS 中性档）

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 35/45/55%（来源：2025→2028E 一致预期 CAGR +165% 系 13.86 亿低基数所致，**禁用**；取正常化假设——2027E 一致预期增速 +110% 至 153.8 亿、2028E +69%，三年正常化中枢取 35-55%）
- 适用性检查：业绩爆发由索尔思并表（2025/10）+ AI 光模块放量驱动，属并购+景气双击，**可用但需折减**；g 不用当年 +428%
- 计算：保守 3.55×35 = 124.3 元；中性 4.10×45 = 184.5 元；乐观 4.64×55 = 255.2 元
- **合理股价区间：124.3 ~ 184.5 ~ 255.2 元**

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 2026E 净利 × 转换率（2026H1 OCF/净利 80.6%，但 capex 52.53 亿 >> OCF、H1 FCF -28.7 亿，扩产期转换率压至 0.65~0.85）；g₁ = 20/28/35%（依据：光模块+AI PCB 产能爬坡节奏）
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=65×0.65=42.3 亿，g₁=20% → 1236.7 亿 → **67.5 元**
  - 中性：FCF₀=75×0.75=56.3 亿，g₁=28% → 2219.1 亿 → **121.1 元**
  - 乐观：FCF₀=85×0.85=72.3 亿，g₁=35% → 3655.9 亿 → **199.6 元**
- **合理股价区间：67.5 ~ 121.1 ~ 199.6 元**（DCF 中性显著低于 PE/PS 中性——反映扩产期自由现金流为负的现实，是五方法中的谨慎锚）

## 四、触发线与操作（Step4）

- 深度买点 = 保守均值×0.9 = **99.1 元**（重仓区）

## 五、结论

- 现价 195.62 元 vs 中性均值 159.1 元 → **高估 23.0%，处于止盈观察区**（已超止盈线 190.9 元，距透支卖出线 226.6 元尚有 16%）
- 操作建议：**持有者减仓 1/3 锁利，空仓者不追高**；等待回落至 167 元以下再评估、135 元以下分批
- 核心前提：本估值成立依赖"H2 光模块收入环比继续爬坡（季均 ≥22 亿）+ 索尔思整合顺利 + Q4 无大额减值"；若 Q3 归母环比 Q2（18.47 亿）下滑，则直接落回保守档 110 元中枢

## 六、后续跟踪清单（目标：判断估值价格能否实现及延续）

### ① 财务指标跟踪（当前值 + 关键阈值）

- 经营现金流：当前 23.84 亿（H1，OCF/净利 80.6%；capex 52.53 亿、FCF -28.7 亿）；阈值：全年 OCF <45 亿或 OCF/净利 <60% → 扩产期现金流恶化，下调 DCF 转换率；capex 若超 110 亿/年需警惕融资摊薄
- 净利增速：当前 +290.1%（H1 归母）；阈值：Q3 单季归母 <18.5 亿（环比下滑）→ 落回保守档重估；全年 <65 亿 → 一致预期证伪信号（对照东北证券 36.3 亿的极端保守情形）
- 毛利率：当前 20.15%（同比 +6.56pct），其中光模块 39.33%/电子电路 18.80%；阈值：覆铜板涨价（年内第 7 轮，2026-08-31 行业报道）下电子电路毛利率跌破 17% 且光模块毛利率跌破 35% → 结构升级逻辑受损，PE 倍数下调

### ③ 隐藏变量（影响估值兑现的因素）

- 索尔思整合与光模块竞争格局：索尔思为 100% 全资子公司（总对价 59.35 亿，2025/10 并表，已过 CFIUS 审查），无少数股权摊薄；但 800G 价格战 + 1.6T 迭代节奏决定 39% 毛利率可持续性；2026/6 一批光模块跨境运输失窃已足额投保、公司称影响极低（2026-07-23 证券日报）→ 方向：整合顺利为正贡献，价格战则为最大下修风险
- 券商分歧（最大预期差）：东北证券 8/28 下调评级至增持、2026E 仅 36.28 亿（vs 主流 72-82 亿），隐含 H2 归母几乎归零的极端假设；若其逻辑（需求/爬坡/减值担忧）被 Q3 业绩部分验证，估值中枢将快速向保守档坍缩
- 政策风险：美国 FCC 禁令与贸易管制对海外业务的潜在影响（东北证券风险提示，2026-08-28）；泰国/马来西亚海外产能为对冲项
- 周期位置：AI 光模块 800G→1.6T 切换的上行中段，CPO/硅光技术路线演进（公司已有布局）为中期变量；2027E 一致预期 +110% 的高预期本身即是风险
- 其他：资产负债率 64.5% + 17 亿美元资本开支 → 后续或有大额融资（摊薄）；汇率波动影响美元收入；大股东减持/解禁：数据缺失，未联网核实到具体安排
