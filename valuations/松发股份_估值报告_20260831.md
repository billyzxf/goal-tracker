## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 10.1872 亿股（来源：财报 CSV + 情景假设）；合理PE = 15/20/25 倍（依据：周期股中枢 15-20 倍上沿 + 高成长溢价至 25 倍；同业中国船舶 13 倍，松发盈利质量与订单增速溢价；券商目标价 200 元隐含 2026E 约 23~25 倍）
- 计算：保守 7.08×15 = 106 元；中性 7.62×20 = 152 元；乐观 8.50×25 = 213 元
- **合理股价区间：106 ~ 152 ~ 213 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：2026E 年末 BPS = 16.9 元（期初 equity 94.52 亿 + 2026E 中性净利 77.6 亿，÷ 股本，未含 70 亿定增；来源：财报 CSV + 情景假设）；合理PB = 4/5/6 倍（锚定 2026E ROE ~44%，属"ROE≥20% → 4-6 倍"档；但周期顶部 ROE 不可持续，取档位下沿至中值）
- 计算：保守 16.9×4 = 68 元；中性 16.9×5 = 85 元；乐观 16.9×6 = 101 元
- **合理股价区间：68 ~ 85 ~ 101 元**
- ⚠️ 交叉验证信号：现价 PB 9.54 显著高于 ROE 锚定合理值——市场按"成长股"而非"周期股"定价，若 2028 年后盈利见顶回落，PB 中枢将向中国船舶（1.7 倍）方向收敛

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 430/472.7/510 亿（来源：外推+一致预期）；合理PS = 2.5/3.0/3.5 倍（依据：中国船舶 PS≈2.9 倍（市值 2617 亿/年营收约 900 亿），松发净利率 15.4% 约为中船 2~3 倍 + 增速溢价）
- 计算：保守 430×2.5÷10.1872 = 106 元；中性 472.7×3.0÷10.1872 = 139 元；乐观 510×3.5÷10.1872 = 175 元
- **合理股价区间：106 ~ 139 ~ 175 元**（现价隐含 2026E PS 约 4.0 倍）

### 3.4 PEG法

- 公式：合理股价 = EPS × g × PEG
- 输入：g = 30/40/50%（来源：2026→2028E 一致预期净利 CAGR 59.9%，去暴增后取正常化增速；非当年 +192% 外推）；PEG = 0.7（**周期股折价**：订单覆盖 2.7 年（高盛 2026-07-08）短于全球船厂 4.3 年，业绩能见度 3~4 年，2030 年后存在周期反转风险）
- 适用性检查：属强周期行业，纯 PEG=1 会给出 300~460 元的荒谬值（类比兆易案例），故按"周期折价 0.7 + 正常化 g"使用，结论仅作上限参考
- 计算：保守 7.08×30×0.7 = 149 元；中性 7.62×40×0.7 = 213 元；乐观 8.50×50×0.7 = 298 元
- **合理股价区间：149 ~ 213 ~ 298 元**

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 2026E 净利 × 转换率 0.55/0.6/0.7（低于常规 0.85~0.9——2026H1 资本开支 101.6 亿超过 OCF 85.1 亿，扩产高峰压制 FCF）；g₁ = 18/28/32%（订单能见度支撑前 5 年，2028 年后增速衰减）
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=72.1×0.55=39.7 亿，g₁=18% → 1076 亿 → **106 元**
  - 中性：FCF₀=77.6×0.60=46.6 亿，g₁=28% → 1837 亿 → **180 元**
  - 乐观：FCF₀=86.6×0.70=60.6 亿，g₁=32% → 2760 亿 → **271 元**
- **合理股价区间：106 ~ 180 ~ 271 元**

- 现价 187.30 元 vs 中性均值 154 元 → **高估 22%，已越过止盈观察线 185 元**（距透支线 223 元尚有 19% 空间）
