## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 2.3957 亿股（来源：财报 CSV + 情景假设）；合理PE = 15/17/19 倍（依据：连锁食品板块中枢 15~20 倍，本公司扣非内生增速 5~15% + ROE 12% + 分红率 69%，取中枢附近；券商目标价隐含 21~25 倍为乐观预期，不作为中性锚）
- 计算：保守 1.18×15 = 17.7 元；中性 1.21×17 = 20.6 元；乐观 1.25×19 = 23.8 元
- **合理股价区间：17.7 ~ 20.6 ~ 23.8 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：BPS = 9.23 元（来源：equity 22.10 亿 ÷ 股本 2.3957 亿，2026Q2）；合理PB = 1.8/2.1/2.4 倍（锚定 ROE 12%（2025 全年 11.97%，2026E 约 12%），属 10-15% 档 → 1.5~2.5 倍，取中枢）
- 计算：保守 9.23×1.8 = 16.6 元；中性 9.23×2.1 = 19.4 元；乐观 9.23×2.4 = 22.2 元
- **合理股价区间：16.6 ~ 19.4 ~ 22.2 元**
- ⚠️ 交叉验证信号：现价 PB 2.10 恰处于 ROE 锚定的中性值——市场基本按"低增长稳定分红资产"定价，未给予新店型成长期权溢价；ROE 若回升至 13%+ 则 PB 锚上移

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 19.3/19.8/20.0 亿（来源：外推，一致预期 20.04 亿）；合理PS = 2.2/2.6/3.0 倍（依据：毛利率 29% 的连锁食品加工，低于高毛利饮料（4~5 倍）、与速冻食品龙头（2~3 倍）相当）
- 计算：保守 19.3×2.2÷2.3957 = 17.7 元；中性 19.8×2.6÷2.3957 = 21.5 元；乐观 20.0×3.0÷2.3957 = 25.1 元
- **合理股价区间：17.7 ~ 21.5 ~ 25.1 元**（现价隐含 2026E PS 约 2.3 倍，处于保守~中性之间）

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 8/11/14%（来源：2025→2028E 净利 CAGR 12.5%（一致预期 2.73→3.89 亿）取正常化，三档围绕 CAGR 浮动）
- 适用性检查：非周期股，**形式上可用**；但 g<15% 时 PEG=1 隐含的 8~14 倍 PE 对稳定分红消费股过于苛刻（分红率 69% 提供额外回报），**本方法仅作估值下限参考**
- 计算：保守 1.18×8 = 9.4 元；中性 1.21×11 = 13.3 元；乐观 1.25×14 = 17.5 元
- **合理股价区间：9.4 ~ 13.3 ~ 17.5 元**（下限参考，不纳入有效均值权重）

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 2026E 净利 × 转换率 0.80~0.88（OCF/净利 106%，轻资产连锁模式现金转化优异，但新店型扩张期 capex 与补贴投入上升，取上沿 0.88/中性 0.85/保守 0.80）；g₁ = 5/8/11%
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=2.83×0.80=2.26 亿，g₁=5% → 36.3 亿 → **15.1 元**
  - 中性：FCF₀=2.90×0.85=2.47 亿，g₁=8% → 44.9 亿 → **18.7 元**
  - 乐观：FCF₀=3.00×0.88=2.64 亿，g₁=11% → 54.2 亿 → **22.6 元**
- **合理股价区间：15.1 ~ 18.7 ~ 22.6 元**

## 五、结论

- 现价 19.15 元 vs 中性均值 18.7 元 → **高估约 2.4%，基本合理**（处于中性持有区间 17.8~19.6 元内；剔除 PEG 失真后 vs 20.1 元则低估 4.7%）
- 操作建议：**持有者继续持有收分红（分红率 69% + 股息率约 3.6%），新增资金等待 15.9~16.5 元分批机会**；现价已隐含中性预期，向上弹性取决于新店型放量证真
- 核心前提：本估值成立依赖 → "单店收入降幅持续收窄至转正 + 小笼包新店型年末达 600 家 + 猪肉成本红利延续"；三者任一证伪则中枢下移至保守档
- 对照：券商目标价 25.0 元（中金 2026-08-23）/ 26 元（华创 2026-08-26）/ 31 元（国泰海通 2026-08-29）隐含新店型成功放量 + 21~25 倍 PE 乐观预期，较本报告中性值高 34%~66%——分歧点在"新店型能否再造一个巴比"，建议以季度门店数与单店数据逐步验证后再上修
