## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 23.2434 亿股（来源：财报 CSV + 情景假设）；合理PE = 60/75/90 倍（依据：现价 128× 高于设备双龙头 62-75× 与澜起 65×；公司 2026-2028 净利 CAGR 约 56%（25.45→96.85），中性 75× 与设备龙头上沿 + 国产 CPU 稀缺溢价匹配，乐观 90× 对应 PEG≈1.4 仍属宽容）
- 计算：保守 1.79×60 = 107.4 元；中性 1.97×75 = 147.8 元；乐观 2.24×90 = 201.6 元
- **合理股价区间：107.4 ~ 147.8 ~ 201.6 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：BPS = 12.53 元（来源：equity 291.14 亿 ÷ 23.2434 亿股，2026Q2）；合理PB = 3.5/4.5/6.0 倍（锚定 ROE 2025 年 11.87%、2026E 约 15%（华泰预测 2026E ROE 18.3%）——跨"10-15% 档 2-3.5 倍"与"15-20% 档 3-5 倍"，ROE 三年翻倍上行给至上沿 + 溢价）
- 计算：保守 12.53×3.5 = 43.9 元；中性 12.53×4.5 = 56.4 元；乐观 12.53×6.0 = 75.2 元
- **合理股价区间：43.9 ~ 56.4 ~ 75.2 元**
- ⚠️ 交叉验证信号：现价 PB 22.5 倍为合理上沿的 3 倍——市场定价的是 2028E ROE 20%+ 与"CPU+DCU 平台型垄断"远期格局，当期 ROE 无法支撑；PB 法仅作下限警示

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 215/223.6/240 亿（来源：平台一致预期 + 情景外推）；合理PS = 8/11/14 倍（依据：毛利率 55% 的高毛利芯片设计公司，参考"高毛利存储（兆易 63% 毛利）PS 6-12 倍"档上浮——收入增速 +55% 高于兆易常规水平，但毛利率趋势向下（大摩预计 2028 年降至 53.3%）限制溢价）
- 计算：保守 215×8÷23.2434 = 74.0 元；中性 223.6×11÷23.2434 = 105.8 元；乐观 240×14÷23.2434 = 144.6 元
- **合理股价区间：74.0 ~ 105.8 ~ 144.6 元**（现价隐含 2026E PS 约 25.5 倍，为中性合理值 11 倍的 2.3 倍）

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 45/56/62%（来源：中性 = 2025A 25.45→2028E 96.85 的 CAGR 56%（一致预期路径）；保守 = 2028E 下修至 78 亿对应 CAGR 45%；乐观 = 2028E 上修至 110 亿对应 CAGR 62%，与大摩"2025-2028 净利 CAGR 69%"的乐观口径衔接）
- 适用性检查：非周期股（信创 + AI 双驱动，非涨价脉冲），可用；中性 g=56% 略超 50%，PEG 结果作交叉参考而非主锚
- 计算：保守 1.79×45 = 80.6 元；中性 1.97×56 = 110.3 元；乐观 2.24×62 = 138.9 元
- **合理股价区间：80.6 ~ 110.3 ~ 138.9 元**

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 2026E 净利 × 转换率（取 0.6/0.75/0.85——2025 年 OCF/净利 82% 为基准上沿，2026H1 为 -24%（备货 75 亿 + 预付 47.7 亿占用），取值留折价）；g₁ = 35/45/55%（一致预期 2026-2028 CAGR 56% 打折扣）
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=41.6×0.60=25.0 亿，g₁=35% → 1263 亿 → **54.3 元**
  - 中性：FCF₀=45.9×0.75=34.4 亿，g₁=45% → 2441 亿 → **105.0 元**
  - 乐观：FCF₀=52.0×0.85=44.2 亿，g₁=55% → 4307 亿 → **185.3 元**
