## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 85.6106 亿股（来源：财报 CSV + 情景假设）；合理PE = 40/50/60 倍（依据：设备同业 62-90 倍打 2/3 折反映代工重资产属性；台积电 25-30 倍 + A 股稀缺溢价；2026E 增速 +46~59% 匹配）
- 计算：保守 0.857×40 = 34.3 元；中性 0.881×50 = 44.0 元；乐观 0.938×60 = 56.3 元
- **合理股价区间：34.3 ~ 44.0 ~ 56.3 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = BPS × 合理PB
- 输入：BPS = 30.15 元（来源：equity 2580.93 亿 ÷ 股本，2026Q2）；合理PB = 1.0/1.5/2.0 倍（锚定 ROE 3.4%，处于折旧前置的周期底部，2027E 盈利放量后有望向 5%+ 回升 → 给周期回升中段 PB）
- 计算：保守 30.15×1.0 = 30.2 元；中性 30.15×1.5 = 45.2 元；乐观 30.15×2.0 = 60.3 元
- **合理股价区间：30.2 ~ 45.2 ~ 60.3 元**
- ⚠️ 交叉验证信号：现价 PB 6.29 vs ROE 3.4%，PB-ROE 严重背离——市场为战略稀缺性/AI 叙事付费，无法用账面盈利解释

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 790/810/840 亿（来源：情景外推，一致预期 803.03 亿）；合理PS = 2.0/2.8/3.5 倍（依据：毛利率 23% ≈ 台积电（毛利率 57%、PS 8-9 倍）的 4 折，对应 PS 3-4 倍，保守打折）
- 计算：保守 790×2.0÷85.6106 = 18.5 元；中性 810×2.8÷85.6106 = 26.5 元；乐观 840×3.5÷85.6106 = 34.3 元
- **合理股价区间：18.5 ~ 26.5 ~ 34.3 元**（现价隐含 2026E PS 约 13 倍，为合理区间的 3.8 倍）

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 23/30/36%（来源：2025→2028E 净利 CAGR 30.1%（50.41→111.0 亿，一致预期）为中性档；保守/乐观档按情景调整 2028E 净利 ±15%；非当年暴增外推）
- 适用性检查：盈利处在上行周期而非脉冲顶部（涨价+稼动率双升），**可用**
- 计算：保守 0.857×23 = 19.7 元；中性 0.881×30 = 26.4 元；乐观 0.938×36 = 33.8 元
- **合理股价区间：19.7 ~ 26.4 ~ 33.8 元**

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，r=10%，g₂=3%
- 输入：基期FCF = 净利 × 转换率 0.85~0.95（来源：财报 CSV；⚠️ 中芯 2026H1 OCF 207.6 亿但 capex 197.3 亿、2025 全年 FCF 为 -398.7 亿，处于强资本开支周期——以净利近似 FCF 显著乐观，结果仅作理论上限参考）；g₁ = 18/22/26%
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=73.4×0.85=62.4 亿，g₁=18% → 1690 亿 → **19.7 元**
  - 中性：FCF₀=75.4×0.90=67.9 亿，g₁=22% → 2144 亿 → **25.0 元**
  - 乐观：FCF₀=80.3×0.95=76.3 亿，g₁=26% → 2798 亿 → **32.7 元**
- **合理股价区间：19.7 ~ 25.0 ~ 32.7 元**

## 四、触发线与操作（Step4）

- 深度买点 = 保守均值×0.9 = **22.1 元**（重仓区）
- 第一买点 = 中性均值×0.85 = **28.4 元**（分批建仓）

- 两剧本：剧本A（涨价周期延续、Q3/Q4 毛利率持续兑现）→ 盈利上修但现价已透支乐观情景 2.9 倍，持有者逢高减仓；剧本B（AI 资本开支降温/管制升级杀跌）→ 现价到第一买点需 -77%，届时重新评估周期位置再定仓位

## 五、结论

- 现价 125.88 元 vs 中性均值 33.4 元 → **高估 277%，深度透支区**（超透支线 45.7 元约 175%）
- 操作建议：**持有者逢高逐步减仓，空仓者坚决不追**；本报告五方法基于报表盈利，现价定价包含"成熟制程涨价周期 + 国产替代战略稀缺性 + A/H 溢价结构"三重独立溢价（华泰 A 股目标价 182 元隐含 2026E PE 262 倍），该溢价能否维持完全取决于 AI 需求外溢的持续性
- 核心前提：本估值成立依赖"H2 毛利率 ≥24% + 涨价可覆盖折旧增量"；若 2027 年成熟制程 ASP 回落，五方法中枢还将下移

## 六、后续跟踪清单（目标：判断估值价格能否实现及延续）

### ① 财务指标跟踪（当前值 + 关键阈值）

- 经营现金流：当前 207.60 亿（2026H1，OCF/净利 465%，折旧驱动；capex/OCF = 95%）；阈值：capex/OCF 连续两季 >110% → 扩产挤占流动性，下调估值中枢；capex/OCF 回落至 <80% → FCF 拐点，估值可信度提升
- 净利增速：当前 H1 归母 +94.1% / 扣非 +57.2%；阈值：全年归母增速跌破 +35% → 切换保守档；跌破 +25% → 一致预期（61 亿下限）证伪，整体下移
- 毛利率：当前 23.16%（H1，Q2 单季 25.3%，Q3 指引 26-28%）；阈值：Q4 实际毛利率 <24% → 涨价逻辑证伪，PE 锚压缩至 35 倍以下；维持 26%+ → 验证上行周期，PE 锚可上探 60 倍
- 应收账款：当前 71.17 亿（占 LTM 营收 9.7%）；阈值：增速超营收增速 15pct → 收入质量预警（当前为正面信号，持续跟踪）
- ROE：当前 3.4%（2025 全年，2026H1 年化约 3.5%）；阈值：2026 全年 <3.0% → PB 锚降至 1.0 倍以下；2027E 回升至 5%+ → PB 锚上移至 2 倍

### ② 业务关键点跟踪（验证信号）

- 产能：Q2 月产能 109.65 万片（8 英寸当量）、利用率 93.7%，Q2 新增约 8000 片/月 12 英寸产能（山西证券 2026-08-21）；验证信号：Q3 产能利用率 ≥93%、Q4 新增产能顺利投放并快速爬坡

- 资本开支：Q2 单季 18.36 亿美元、全年超 80 亿美元（高盛 2026-08）；验证信号：专用存储/PMIC/模拟产线投资落地、先进封装研究院项目进展；中芯北方 49% 少数股权收购完成时点（华泰 2026-05-16）

### ③ 隐藏变量（影响估值兑现的因素）

- 少数股东损益（最关键）：Q2 少数股东损益占净利润比例 34.6%（同比 +25pct，山西证券 2026-08-21），中芯南方/京城/东方利润大头不归属上市公司 → 归母净利被结构性稀释，是表观 PE 高企的重要原因；中芯北方 49% 股权收购若完成将增厚归母利润（正向），新厂少数股权占比继续提升则反向
- AH 溢价结构：85.61 亿总股本中 H 股占比约 2/3，总市值按 A 股价计；2025 年初以来 AH 溢价率均值约 105%（华泰 2026-05-16），H 股价格（现值本地数据缺失）是 A 股定价的锚定变量之一
- 政策风险：美对华设备/技术出口管制升级（华泰风险提示）→ 扩产节奏受制；国产替代加速（长江存储三期国产设备占比已破 50%，2026-07 报道）→ 中芯作为国产芯片产能承接方需求端受益
- 周期位置：成熟制程涨价周期早中段（大摩 2026-05-19 预计 2027 下半年或现成熟制程短缺）；若 AI 资本开支降温，涨价与稼动率双逻辑将同步逆转——现价对周期拐点极度敏感
