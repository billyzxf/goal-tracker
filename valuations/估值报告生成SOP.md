# 公司估值报告·生成 SOP

> 定位：每对一家公司做估值，按本 SOP 引用数据 → 复制模板 → 生成报告，存放在本目录。
> 上位文档：《[估值五步法_完整说明文档](../scripts/估值五步法_完整说明文档.md)》（方法原理/倍数参考/避坑清单以该文档为准）
> 报告命名：`{公司名}_估值报告_{YYYYMMDD}.md`（重估时新增日期版本，不覆盖旧版）

---

## 一、取数（Step1，全自动化）

**先查本地、再决定抓取**：取数前先检查本地文件（`data/financial/`、`data/prices/`、`data/forecast/`）是否已存在该公司数据，且已覆盖最新报告期/最新交易日——**已满足则直接使用本地数据，禁止重复执行脚本重复获取**。仅当：
- 本地无该公司 CSV，或
- 本地数据未包含最新报告期（如新季报已披露），或
- 行情快照不是最新交易日

才执行对应脚本。

```bash
py scripts/fetch_financial.py --ticker {代码}.SH --quarters 18      # 财务三表
py scripts/fetch_profit_forecast.py --ticker {代码}.SH             # 一致预期/券商预测
py scripts/fetch_prices.py                                         # 全部公司行情快照
```

- 财务数据：`data/financial/{代码}_{公司}.csv`（营收/净利/扣非/同比/毛利率/净利率/ROE/负债率/经营现金流/资本开支/应收账款/存货/合同负债/货币资金）
- 行情快照：`data/prices/当前股价_{YYYYMMDD}.csv`（现价/PE(动)/PB/总市值/总股本）
- 一致预期：`data/forecast/盈利预测_{公司}.csv`
- 同业对比：从股价 CSV 挑同行业公司横向比较 PE/PB → 人工定"合理倍数"
- 浏览器「公司估值」导入 CSV 后，分季度财务表可按季度渐变色行对齐同比数据

## 二、生成报告（Step2~4）

1. 复制 [`_报告模板.md`](_报告模板.md) 改名为 `{公司名}_估值报告_{YYYYMMDD}.md`
2. 按模板逐节填写：数据快照 → 三情景 → 五方法 → 触发线 → 结论 → 跟踪清单

## 三、报告硬性要求（不可省略）

1. **五方法逐一计算**：市盈率法/市净率法/市销率法/PEG法/DCF法，每种方法必须写清
   ①计算公式 ②输入数据（注明来源：财报CSV/一致预期/人工假设）③保守/中性/乐观三档计算过程 ④合理股价区间。
   **禁止只给单一结论**；不适用某方法时写明理由（如周期股禁用 PEG），不得静默跳过。
2. **交叉验证**：五方法中性值取均值，输出四档触发线（深度买点/第一买点/中性持有/止盈观察/透支卖出）。
3. **自动附带「后续跟踪清单」章节**，**必须用列表形式（禁用表格）**，固定三小节：
   - **① 财务指标跟踪**：经营现金流、净利增速、毛利率、应收账款、ROE——每项给出当前值 + 关键阈值（触及即触发重估/证伪）
   - **② 业务关键点跟踪**：产能/订单/新品/客户——每项给出可验证的信号（如"大客户新订单公告""产能利用率>90%"）
   - **③ 隐藏变量**：参股公司股权、周期位置、政策风险等影响估值兑现的因素，逐项说明影响方向
4. **跟踪清单必须联网补充最新信息**：生成时须联网搜索该公司**最新券商研报观点**（评级/目标价/盈利预测上下调、核心逻辑变化）与**行业动态**（订单/政策/竞争格局/上下游价格），并将结果融入三小节：
   - 阈值校准：关键阈值参考最新券商一致预期与目标价隐含假设，不闭门造车
   - 业务关键点：补充行业最新信号（如产业链涨价/扩产/大单），给出比模板占位符更具体的验证信号
   - 隐藏变量：纳入搜索发现的最新事件（并购/管制/减持/诉讼等），标注信息日期
   - 无法联网或搜索无结果时，在清单末尾注明"未联网核实，阈值为本地数据推算"
5. **目标**：跟踪清单服务于一个判断——估值价格能否实现及延续；每项阈值都要能回答"什么情况下证明估值错了"。

## 四、更新纪律（Step5）

- 每季财报披露后：重跑取数命令 → 对照跟踪清单逐项核验 → 有证伪/超预期信号则重算估值，生成新日期版本报告
- 报告末尾「复核记录」追加一行：日期 | 事件 | 结论变化
