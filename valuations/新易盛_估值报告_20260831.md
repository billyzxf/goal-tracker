## 三、五方法估值（Step3）

### 3.1 市盈率法（PE）

- 公式：合理股价 = EPS × 合理PE
- 输入：EPS = 三情景净利 ÷ 13.9426 亿股（来源：财报 CSV + 情景假设）；合理PE = 24/28/32 倍（依据：2026E 增速 +61~108% 匹配；与旭创倍数对齐——同增速档光模块双龙头，高盛给 2027E 27.8 倍为本估值上限佐证）
- 计算：保守 11.02×24 = 264.5 元；中性 12.22×28 = 342.2 元；乐观 14.22×32 = 455.0 元
- **合理股价区间：264.5 ~ 342.2 ~ 455.0 元**

### 3.2 市净率法（PB）

- 公式：合理股价 = 2026E 年末 BPS × 合理PB
- 输入：年末 BPS =（2025 末 equity 180.64 亿 + 2026E 净利×留存 0.85，分红数据缺失按 15% 分红率假设）÷ 股本 → 保守 22.3 / 中性 23.3 / 乐观 25.0 元；合理PB = 12/15/18 倍（依据：PB = PE×ROE 自洽，2026E 期末 ROE 49~57%——2025 年 72.75% 不可持续，按净资产快速增厚后口径）
- 计算：保守 22.3×12 = 267.6 元；中性 23.3×15 = 349.5 元；乐观 25.0×18 = 450.0 元
- **合理股价区间：267.6 ~ 349.5 ~ 450.0 元**
- ⚠️ 交叉验证：现价 PB 22.90 低于乐观档年末合理 PB，主要因净资产年内随利润快速增厚（H1 equity 已较 2025 年末 +35%），PB 法对本类高 ROE 公司偏滞后

### 3.3 市销率法（PS）

- 公式：合理股价 = 2026E营收 × 合理PS ÷ 总股本
- 输入：2026E 营收 = 439.6/482.8/540.4 亿（来源：情景外推，一致预期 526.0 亿）；合理PS = 8.4/10.0/11.7 倍（依据：PS = PE×净利率自洽，净利率 35~37%——高毛利率为同业最高，支撑 PS 高于旭创）
- 计算：保守 439.6×8.4÷13.9426 = 264.9 元；中性 482.8×10.0÷13.9426 = 346.3 元；乐观 540.4×11.7÷13.9426 = 453.2 元
- **合理股价区间：264.9 ~ 346.3 ~ 453.2 元**

### 3.4 PEG法

- 公式：合理股价 = EPS × 未来3年复合增速g（PEG=1）
- 输入：g = 25/35/45%（来源：正常化增速——2026→2028E 一致预期 CAGR 58%，考虑 2028 年后行业增速回落至 25-30%，取正常化区间；不用当年 +79~108%）
- 适用性检查：2023 年曾负增长（-23.9%）、2024-2025 连续暴增，属 AI 驱动的高波动成长而非稳态复利，**可用但需强正常化**；g 取值偏保守
- 计算：保守 11.02×25 = 275.5 元；中性 12.22×35 = 427.7 元；乐观 14.22×45 = 639.9 元
- **合理股价区间：275.5 ~ 427.7 ~ 639.9 元**（中性值高于其他方法，作上限参考）

### 3.5 DCF折现法（两阶段）

- 公式：股权价值 = Σ FCFₜ/(1+r)ᵗ + TV/(1+r)⁵，TV = FCF₅×(1+g₂)/(r-g₂)，r=10%，g₂=3%
- 输入：基期 FCF = 2026E 净利 × 转换率（2025 OCF/净利 80.8%，2026H1 降至 21.5% 属锁料备货压制，转换率取 0.70/0.80/0.90）；g₁ = 20/25/30%
- 计算（股权价值 → 每股）：
  - 保守：FCF₀=153.6×0.70=107.5 亿，g₁=20% → 3147.4 亿 → **225.8 元**
  - 中性：FCF₀=170.3×0.80=136.2 亿，g₁=25% → 4814.4 亿 → **345.3 元**
  - 乐观：FCF₀=198.3×0.90=178.5 亿，g₁=30% → 7571.4 亿 → **543.0 元**
- **合理股价区间：225.8 ~ 345.3 ~ 543.0 元**
