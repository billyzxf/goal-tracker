🔎 逐个平台详细评测

🥇 Trading Economics

🔗 tradingeconomics.com/china
  • 覆盖 200+国家、超2000万指标
  • CPI、PPI、GDP、PMI、M2、利率、就业、贸易、房地产等全覆盖
  • 数据更新最为及时（发布后几分钟内即更新）
  • 交互式图表可自定义时间范围、对比多国数据
  • 提供 REST API（需注册）和 Excel 下载
  • 支持中、英文等多语言
✅ 优势
图表最美观；更新最快；全球数据可比；API可用
⚠️ 不足
免费版历史数据有限；部分指标需付费查看全部年份

🥈 东方财富数据中心

🔗 data.eastmoney.com/center/macro.html
  • 中国宏观经济数据 覆盖面最广 的免费平台
  • 逐月/逐季发布：CPI、PPI、GDP、PMI、M2、社融、存贷款、利率、进出口、工业增加值、消费零售、固定资产投资等
  • 额外提供：存款准备金率历史、税收收入、外汇储备、黄金储备
  • 数据更新及时，发布时间紧跟统计局
  • 表格形式为主，部分指标有简单走势图
✅ 优势
完全免费；数据类目国内最全；一页览尽所有核心指标
⚠️ 不足
图表交互性弱；历史数据需逐页翻找；单页数据密度过高

🥉 国家统计局 - 国家数据

🔗 data.stats.gov.cn
  • 官方一手数据源，所有其他平台数据的最终出处
  • 支持按指标 × 时间 × 地区三维交叉查询
  • CPI可查询到各省份、各分类（食品/服务/居住等）的详细数据
  • 提供统计年鉴、普查数据等深度资料
  • 数据颗粒度最细，历史数据可追溯数十年
✅ 优势
权威性无出其右；数据颗粒度最细；可跨地区比较
⚠️ 不足
界面老旧；无M2/利率数据（央行管辖）；交互体验一般

中经数据 (CEI)

🔗 ceidata.cei.cn
  • 国家信息中心旗下，专注中国宏观经济统计 30年
  • 整合统计局、海关总署、央行等多源数据
  • 覆盖 GDP、人口、能源、财政、金融等上百个主题
  • 提供市县级区域经济数据和海量统计年鉴
  • 有配套的 CEI 统计数据库和 API 接口
✅ 优势
专业性强；数据整合度高；覆盖市县级别
⚠️ 不足
部分数据需付费；界面偏学术风格；图表不够现代

Wind (万得) 金融终端

🔗 wind.com.cn
  • 中国金融数据服务 第一大平台，机构标配
  • EDB（经济数据库）：全球宏观及行业经济大数据
  • 数据覆盖：股票、债券、基金、外汇、商品、宏观全品类
  • 支持智能搜索、可视化分析、Excel 动态提取
  • 7×24小时实时行情
✅ 优势
数据最全最强；专业图表与分析工具；Excel插件无敌
⚠️ 不足
个人用户基本无法使用；需机构购买；年费数万元起步

💡 我的推荐组合

日常查月度 CPI/PPI/GDP/PMI → 用 Trading Economics（图表最美，更新最快，免费版够用）

需要国内最全的免费数据一页看齐 → 用 东方财富数据中心（M2、社融、信贷等央行数据也都有）

需要最权威的细分/地区数据（比如某省CPI分类指数） → 用 国家统计局 - 国家数据（无可替代的数据颗粒度）

查 LPR / Shibor / 国债收益率 → 用 中国货币网 + 中国人民银行

如果你是机构用户或有朋友在金融机构 → Wind 万得 EDB 是终极答案，Excel直接拉数，一键出图
